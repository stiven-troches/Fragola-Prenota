# FRAGOLA PRENOTA (prototipo)

Plataforma de reservas para barberías, spas y salones. Archivo único (`index.html`), JavaScript sin librerías.

## Ver en línea
Activa GitHub Pages: Settings → Pages → Deploy from a branch → `main` / `(root)`.
Quedará en `https://TU-USUARIO.github.io/NOMBRE-REPO/`.

## Importante
- Es un **prototipo**: sin servidor, base de datos ni autenticación real.
- Los datos viven en la memoria del navegador y se pierden al recargar.
- Los PIN de demostración (administrador 1234, empleados 1111) no protegen datos reales.
- Probado solo en Chromium (simulación). No probado en teléfonos reales, Safari ni Firefox.
